# 루키 × 일본 — 혁신(크리에이티브) 광고 기획서

**캠페인**: NAVER LABS 루키 일본 시장 진출  
**작성**: 혁신 광고 제작팀  
**빅 아이디어**: 「공간의 마찰을 환대로」 — "배달 로봇" 기억을 덮어쓰기

---

## 1. 혁신 전략

**「체험·이벤트로 카테고리 리프레이밍」**

기존 광고 틀(15초 영상, 배너)을 넘어, **직접 경험**으로 "루키 = 공간·안내·환대" 연상을 만든다.  
KPI: "루키 = 배달" 검색 연상 감소, "루키 = 공간·안내·환대" 연상 증가

---

## 2. 「ルーキーと歩く空間」(루키와 걷는 공간)

### 개요

파일럿 공간 한정, **루키와 함께하는 30분 가이드 투어**.  
헤맴·숨은 명소·대기 추천을 루키가 실시간 안내.

| 항목 | 내용 |
|------|------|
| **대상** | B2C 체험 → SNS → B2B 화제성 |
| **정원** | 1회 6명, 1일 4회 |
| **예약** | LINE·웹, QR (옥외 연동) |
| **경로** | 입장 → 중정 → F&B → 이벤트존 → 출구 (3대 모먼트 각 1회) |
| **산출** | #ルーキー #空間体験 UGC, B2B 사례 영상 소재 |

**차별**: 페퍼(고정 접객) vs 루키(공간 전체 이동·맥락 이해)

---

## 3. 「待ち時間のおもてなし」(대기 시간의 환대)

### 개요

인기 F&B·전시 **대기열**에서 루키가 다국어 추천·미니 콘텐츠·소소한 환대 제공.

| 항목 | 내용 |
|------|------|
| **장면** | 대기 10분+ 구간, 지루함 → 루키 개입 |
| **콘텐츠** | "이 층 숨은 명소", "대기 중 볼 전시", 다국어 퀴즈 |
| **KPI** | 대기 만족도, F&B·전시 추가 방문, SNS |
| **B2B** | 운영 KPI — "대기 = 기회" 프레이밍 |

**혁신 포인트**: 대기를 **손실**이 아닌 **환대 모먼트**로 재정의

---

## 4. 「空間マスター・サミット」(공간 마스터 서밋)

### 개요

도쿄 CX·운영 디렉터 초청, 아자부다이급 사례 + PoC 제안.  
"공간 마스터" 포장을 **B2B 언어**로.

| 항목 | 내용 |
|------|------|
| **일시** | Phase 1 W3-4 |
| **장소** | 파일럿 공간 또는 도쿄 컨퍼런스 |
| **참석** | CX·운영 디렉터 50+ |
| **프로그램** | ① 루키 체험 ② 사례 발표 ③ PoC 제안 ④ Q&A |
| **산출** | B2B 리드 20+, 미팅 요청 |

**방어 카드**: 페퍼 차별, 재난 오프라인, 프라이버시 Charter

---

## 5. 재난·オフライン デモ (재난·오프라인 데모)

### 개요

**통신 차단 시뮬레이션** → 오프라인 폴백 작동 — **신뢰**를 쇼케이스로.

| 항목 | 내용 |
|------|------|
| **대상** | B2B 방어·차별 |
| **시나리오** | Wi-Fi·LTE 차단 → 루키 로컬 안내·대피 경로 표시 |
| **장소** | 서밋·파일럿 공간 데모존 |
| **메시지** | "핵심 기능은 오프라인에서도 작동" |

**차별**: 클라우드 의존 = 약점이 아닌, **오프라인 폴백 = 강점**

---

## 6. プライバシー・チャーター (프라이버시 Charter)

### 개요

**"空間は知る、個人は識別しない"** (공간은 알고, 개인은 식별하지 않는다) 투명 공표 + 현장 설명.

| 항목 | 내용 |
|------|------|
| **형식** | 웹 페이지 + 현장 POP + 서밋 배포 |
| **내용** | 공간지능 O / 개인 식별·기록 X, 데이터 처리 원칙 |
| **대상** | B2B·B2C 신뢰 |
| **연계** | 법무·현지 규제 검수 |

**혁신**: 프라이버시를 **숨기지 않고** 브랜드 자산으로

---

## 7. 「逆転体験」(역전 체험) — 바이럴 아이디어

### 개요

**"루키 없이 30분" vs "루키와 30분"** — 같은 공간, 다른 경험.  
Before/After를 방문객이 직접 비교.

| 항목 | 내용 |
|------|------|
| **형식** | A/B 그룹, 설문 + SNS 챌린지 |
| **해시태그** | #ルーキー体験 #空間の違い |
| **바이럴** | "루키 있으면 vs 없으면" 비교 영상 |
