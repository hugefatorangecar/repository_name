## 01. AE 기획서

> 상세: `01_ae_brief.md`

### 핵심 요약

**배경**: 엔저 인바운드 급증 + 서비스업 인력난 + "배달 로봇" 카테고리 한계 → 공간 경험 로봇 리프레이밍 필요

**3대 모먼트**

| 마찰 | 루키의 환대 | 감정 전환 |
|------|-------------|-----------|
| 헤맴 | 말하기 전 다국어 안내 | 혼란 → 안심 |
| 기다림 | 대기 중 추천·환대 | 공백 → 즐거움 |
| 불안 | 재난·응급 다국어 안내 | 불안 → 신뢰 |

**논리 체인**: 공간지능 → 24시간·다국어 → 마찰 감소 → 체류·재방문↑ → 운영 KPI·화제성↑ → 도입 확대

**톤앤매너**: 「조용한 프리미엄, 따뜻한 존재감」 — 오모테나시·절제·품격

**사실 vs 포장**
- 사실: 공간지능, 자율주행, 다국어, 24시간
- 포장: "공간 마스터" (경험적 은유)
- 방어: 페퍼 차별, 오프라인 폴백, 프라이버시(공간 O / 개인 X)

**로드맵**: Phase 0 준비 → Phase 1 B2B 파일럿 → Phase 2 B2C 인지 → Phase 3 카테고리 정착

## 실행 체크리스트

### Phase 0 (D-60 ~ D-30)
- [ ] 일본어 카피·법무·프라이버시 검수
- [ ] 파일럿 공간 1~2곳 MOU
- [ ] 3대 모먼트 KPI 베이스라인
- [ ] B2B 제안서·90초 스크립트 확정

### Phase 1 — B2B (D-30 ~ D+90)
- [ ] B2B 디지털·LinkedIn 캠페인
- [ ] 空間マスター・サミット 개최
- [ ] 파일럿 가동·A/B
- [ ] 사례 영상·백서 (PoC→본계약 2건+)

### Phase 2 — B2C (D+60 ~ D+180)
- [ ] 현장 POP·15/30초 영상·SNS
- [ ] ルーキーと歩く空間 체험 (#ルーキー 1,000+)
- [ ] 옥외 DOOH·래핑
- [ ] 2차 파일럿·확장 PR

### Phase 3 — 정착 (D+180~)
- [ ] "공간 경험 로봇" 업계 용어화
- [ ] APAC 확장 템플릿
- [ ] B2B2C flywheel 가동

### 매체별 착수
- [ ] 이미지: 3컷 키비주얼 → POP·SNS
- [ ] 영상: 15/30/90초 제작·다국어
- [ ] 옥외: DOOH·래핑 (공간명 연계)
- [ ] 혁신: 서밋 → 체험 → Charter
