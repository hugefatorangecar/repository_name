01 AE 기획서

상세: 01_ae_brief.md

배경

엔저 인바운드 급증 + 서비스업 인력난 + "배달 로봇" 카테고리 한계 → 공간 경험 로봇 리프레이밍 필요

3대 모먼트

마찰루키의 환대감정 전환
헤맴말하기 전 다국어 안내혼란 → 안심
기다림대기 중 추천·환대공백 → 즐거움
불안재난·응급 다국어 안내불안 → 신뢰

논리 체인

공간지능 → 24시간·다국어 → 마찰 감소 → 체류·재방문↑ → 운영 KPI·화제성↑ → 도입 확대

톤앤매너

「조용한 프리미엄, 따뜻한 존재감」 — 오모테나시·절제·품격

사실 vs 포장

  • 사실 공간지능, 자율주행, 다국어, 24시간
  • 포장 "공간 마스터" (경험적 은유)
  • 방어 페퍼 차별, 오프라인 폴백, 프라이버시 (공간 O / 개인 X)

로드맵

Phase 0 준비 → Phase 1 B2B 파일럿 → Phase 2 B2C 인지 → Phase 3 카테고리 정착

02 핵심 카피

상세: 02_copy.md

구분한국어일본어
메인 헤맬 때, 루키가 먼저 곁에 있다 迷ったとき、ルーキーが先にそばにいる
감성공간이 당신을 기억하는 순간, 루키가 거기 있다空間があなたを覚えている、その瞬間にルーキー
이성체류는 길어지고, 불안은 줄어든다滞在は長く、不安は減る — 空間を読むルーキー
서브헤맬 때, 기다릴 때, 불안할 때迷ったとき、待つとき、不安なとき
빅아이디어공간의 마찰을 환대로空間の摩擦を、おもてなしに
B2B: 「인력을 더 뽑는 시대는 끝났다. 공간이 손님을 맞이하는 시대다」
